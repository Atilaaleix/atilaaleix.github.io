0

Antes de tudo: você tem Node?

O Mac não vem com ele. É a única coisa que precisa ser instalada.

Abra o Terminal (Cmd+Espaço, digite "terminal", enter) e cole:

$ node -v

Se responder algo como v22.14.0 — qualquer número 18 ou maior — pule para o passo 1.

Se disser "command not found"

Vá em nodejs.org, baixe o instalador macOS Installer (.pkg) — no Mac com chip M1/M2/M3/M4 é a versão ARM64. Clique duas vezes, avance até o fim.

Feche o Terminal e abra de novo depois de instalar. Ele só enxerga o Node novo numa janela nova.

1

Baixar

Uma pasta com os arquivos. Nada é instalado no sistema.

$ cd ~/Documents $ git clone -b claude/tamagotchi-file-organizer-xpa9x3 \ https://github.com/atilaaleix/atilaaleix.github.io.git pastinha-teste $ cd pastinha-teste/pastinha

Daqui pra frente, todo comando é dado dentro desta pasta. Se você fechar o Terminal e voltar depois, refaça só o cd:

$ cd ~/Documents/pastinha-teste/pastinha
Se o Mac pedir para instalar as ferramentas de desenvolvedor

Ao digitar git pela primeira vez, o macOS abre uma janela oferecendo instalar as Command Line Tools. Clique em Instalar e espere. É uma vez só, e é da Apple.

2

Ver se a máquina está pronta

Não lê nenhum arquivo seu. Só confere se dá pé.

$ node cli.js doctor
o que você vai ver
Pastinha · exame de admissão (macOS) OK Node 18 ou mais novo v22.14.0 OK consegue ler suas pastas OK detector de tipo por bytes javascript puro !! Ollama respondendo http://127.0.0.1:11434 OK vigia ~/Downloads OK vigia ~/Desktop OK guarda em ~/Pastinha
O "!!" do Ollama é esperado

Ollama é o modelo de IA local, e ele é opcional. Todos os números do relatório foram medidos sem ele. Pode ignorar completamente — o bicho funciona só com as regras, que é a maior parte do trabalho.

Aqui o macOS vai te interromper

Vai aparecer uma janela: "Terminal" gostaria de acessar arquivos na sua pasta Downloads. Clique em OK. Vai aparecer de novo para Área de Trabalho e Documentos — OK nas três.

Se você clicar em Não permitir sem querer, o programa vai achar que seu disco está vazio e não vai reclamar. Para consertar: Ajustes do Sistema → Privacidade e Segurança → Arquivos e Pastas → Terminal e ligue as chavinhas.

3

Brincar na caixa de areia primeiro

Bagunça de mentira, num canto isolado. Nenhum arquivo seu é tocado.

Este passo é opcional, mas vale um minuto: você vê o formato de tudo sem risco nenhum antes de apontar para os seus arquivos de verdade.

$ node cli.js sandbox # monta 26 arquivos de mentira $ node cli.js scan # mostra o que ele faria, sem mover $ node cli.js scan --apply # decide um por um, você aprova cada
exemplo real da saída do scan
Contrato Locação Vila Mariana.pdf → Clientes/{cliente}/Contratos/2026-09-11__contrato-locacao-vila-mariana.pdf 45% · nome:contrato · O nome indica contrato — mas preciso saber qual cliente boleto_condominio_março.pdf → Financeiro/Contas/2026-09-11__boleto-condominio-marco.pdf 85% · nome:boleto+generico · O nome indica boleto

Os {chaves} são os espaços que ele ainda não sabe preencher, e a porcentagem é a confiança. Abaixo de 85% ele pergunta em vez de agir.

Importante antes do passo 4

O comando sandbox aponta a configuração para a caixa de areia. Para voltar aos seus arquivos de verdade, rode node cli.js live. Se pular isso, o passo 4 vai continuar mexendo na bagunça de mentira.

4

A primeira vez, de verdade

Varre o disco, faz 8 perguntas, propõe a árvore, executa. Um comando só.

$ node cli.js live # volta para os seus arquivos (se você fez o passo 3) $ node cli.js comecar

A única pergunta em que eu mudaria o padrão

Na pergunta 8 o padrão é "pergunta sempre". É o mais seguro, mas com ele você vê pouca coisa se mexer sozinha.

Para a demonstração ficar interessante, escolha a opção 2 — "move sozinho só o óbvio". Ele passa a guardar sozinho instalador, fonte, captura de tela e boleto, e continua perguntando em tudo que envolve projeto ou cliente.

5

Deixar vivo

Fica rodando. Todo arquivo que cair em Downloads ele pega.

$ node cli.js viver

Deixe essa janela aberta e baixe qualquer coisa no navegador. Em alguns segundos aparece a linha.

saída real
Pastinha vivo. vigiando ~/Downloads e ~/Desktop guardei Nota Fiscal 2291.pdf → Financeiro/Notas/ 88% vi Fatura Vivo Setembro.pdf → Financeiro/Contas/ 85%

guardei = ele moveu. vi = ele sabe para onde vai mas está esperando você liberar, porque você pediu para ele perguntar.

Ctrl+C para parar. Ele não fica em segundo plano nem se instala em nada — quando você fecha a janela, acabou.

Por que um arquivo às vezes demora 6 segundos

Ele espera o arquivo parar de crescer antes de encostar. Um download de 2 GB não é movido no meio do caminho. Se você baixar e olhar na mesma hora, espere uns segundos.

6

Achar

Organizar sem achar é mudar o problema de lugar.

$ node cli.js achar "boleto do condominio"
saída real
* 2026-09-11__boleto-condominio-marco.pdf ~/Pastinha/Financeiro/Contas antes: boleto_condominio_março.pdf

Repare no "antes:". Ele procura também pelo nome antigo — você não precisa lembrar do nome novo que ele deu. Procura por nome, por caminho, pelo texto de dentro do arquivo e pela origem do download.

E para ver a história inteira de um arquivo:

$ node cli.js proveniencia "boleto"
saída real
antes se chamava .... boleto_condominio_março.pdf e morava em ......... ~/Downloads chegou em ........... 2026-09-11 estava ao lado de .... A0077.MP4 Contrato Locação Vila Mariana.pdf

Desfazer, e apagar tudo

A parte mais importante. Testei os dois.

$ node cli.js undo # desfaz o último movimento $ node cli.js undo --today # desfaz tudo que ele fez hoje

Os arquivos voltam para a pasta original com o nome original, acento e cedilha inclusive. Eu verifiquei: 4 arquivos movidos, 4 voltaram idênticos, e a pasta de destino ficou vazia.

Para remover a Pastinha do Mac

$ node cli.js undo --today # primeiro devolve os arquivos $ rm -rf ~/.pastinha # configuração e memória $ rm -rf ~/Documents/pastinha-teste # o programa

A pasta ~/Pastinha com o que ele organizou fica — é sua. Se quiser, apague também. Não existe nada instalado no sistema, nenhum serviço em segundo plano, nenhuma extensão.

!

O que eu espero que dê errado

Dizer antes é mais útil do que explicar depois.

O perfil vai errar

Você não é só uma das 11 profissões da lista. Ele vai chutar uma e provavelmente com "confiança baixa". A pergunta 1 conserta — escolha na mão.

RAW pode virar "imagem"

Tem um defeito conhecido na leitura dos bytes: CR2, NEF, ARW e DNG são TIFF por dentro, e a assinatura do TIFF casa primeiro. Está na lista de conserto, não está consertado.

Cliente novo vira pergunta

O primeiro arquivo de um cliente que ainda não tem pasta sempre pergunta — mesmo com o nome dele escrito dentro do PDF. Falta a captura por conteúdo.

A varredura pode truncar

Ela para em 120 segundos. Num Mac com biblioteca de Fotos grande ela vai bater o limite e avisar. Truncada ela ainda funciona, só com diagnóstico mais pobre.

iCloud pode atrapalhar

Se sua Área de Trabalho e Documentos estão no iCloud, pode haver arquivo que está só na nuvem. Ele lê nome e data normalmente, mas o diagnóstico fica incompleto.

Disco externo não entra

A varredura olha a sua pasta pessoal. Se o acervo está num SSD externo, ele não vai ver — ainda não dá para apontar para /Volumes pelas perguntas.
